# ⌚ Smartwatch — Diseño de PCB + Firmware

Diseño íntegro (hardware + firmware) de un smartwatch: esquemático, layout de PCB multicapa en KiCad y programación del microcontrolador.

## 📋 Descripción

Proyecto personal en el que desarrollé de principio a fin un dispositivo wearable, cubriendo tanto la parte de electrónica (diseño de PCB) como la de software embebido (firmware de control). El objetivo fue enfrentarme al ciclo completo de un producto electrónico: desde el esquemático hasta el código que corre en el propio dispositivo.

## 🛠️ Stack técnico

- **Diseño de PCB:** KiCad (esquemático + layout multicapa)
- **Firmware:** C/C++ (Arduino framework)
- **Hardware:** microcontrolador programado vía Arduino IDE

## 📁 Estructura del repositorio

- `final_v2.ino` — firmware principal del smartwatch
- `hardware.h` — definiciones de pines y configuración de hardware

> Nota: el esquemático y los archivos de PCB en KiCad se pueden añadir aquí como carpeta `/hardware` (o enlazar si se gestionan aparte).
